PayBridge

Scotiabank eCom+ for Odoo 19 Enterprise

A direct connection between your Scotiabank hosted checkout and Odoo's native payments, invoices and accounting.

One connected payment record

Accept card payments from invoice links, sales quotations and website checkout. Follow the payment from its bank order reference to the Odoo transaction, customer payment and journal entry. Reconcile the actual bank settlement using Odoo's existing tools.

Native accounting

Standard journals, customer payments, invoice matching and reconciliation.

Verified bank results

Standard request and response signatures with immutable payment-attempt matching.

Clear configuration

Separate test and live credentials, native currency controls and connection diagnostics.

Built for the hosted payment flow

Choose direct redirect, the original SPXCORP branded handoff, or an embedded bank page. Configure bank language, a sandbox-only USD simulation and safe diagnostics in the provider settings. Live payments always use the actual order currency.

Customers enter card details on the Scotiabank payment page. Bank notifications confirm payments independently of the customer returning to Odoo. PayBridge uses the existing Store ID and Shared Secret, without requiring optional bank features.

This release supports hosted sale payments. Gateway refunds, manual capture, voids, saved cards and recurring charges are not included. Enterprise Accounting is required; Sales and eCommerce connect when installed.
